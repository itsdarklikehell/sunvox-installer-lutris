# Contributing

Bedankt voor je interesse in bijdragen aan sunvox-installer-lutris!

## Hoe bij te dragen

1. Fork de repository
2. Maak een feature branch (`git checkout -b feature/AmazingFeature`)
3. Commit je wijzigingen (`git commit -m 'Add some AmazingFeature'`)
4. Push naar de branch (`git push origin feature/AmazingFeature`)
5. Open een Pull Request

## Stijl-richtlijnen

- Volg de bestaande code-stijl
- Schrijf duidelige commit messages
- Voeg toegepaste tests toe
- Update documentatie indien nodig

## Code of Conduct

Door deel te nemen aan dit project, ga je akkoord met de [Code of Conduct](CODE_OF_CONDUCT.md).

## Licentie

Door bij te draag te komen, ga je ermee akkoord dat je bijdragen gelicenseerd worden onder de [MIT License](LICENSE).
