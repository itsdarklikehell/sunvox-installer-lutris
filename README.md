# sunvox-installer-lutris

SunVox installer voor Lutris.

## Installatie

```bash
git clone https://github.com/itsdarklikehell/sunvox-installer-lutris.git
cd sunvox-installer-lutris
./install.sh
```

## Gebruik

Start SunVox via Lutris.
