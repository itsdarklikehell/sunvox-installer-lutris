# sunvox-installer-lutris

SunVox installer for Lutris on Linux.

## Requirements

- Lutris installed
- Wine (for running SunVox on Linux)

## Installation

```bash
git clone https://github.com/itsdarklikehell/sunvox-installer-lutris.git
cd sunvox-installer-lutris
chmod +x sunvox-installer.sh
./sunvox-installer.sh
```

## Usage

The installer downloads and configures SunVox for use with Lutris. After installation, launch SunVox through Lutris.
