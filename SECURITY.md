# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

Als je een veiligheidslek vindt, meld dit dan op de volgende manier:

1. **Open geen publiek issue** voor gevoelige bevindingen
2. Stuur een privé bericht naar de maintainers
3. Beschrijf de problemen stap-voor-stap
4. Voeg indien mogelijk proof-of-concept toe

We streven ernaar om:

- Binnen 48 uur te reageren op de melding
- Binnen 7 dagen een beoordeling te geven
- Zo snel mogelijk een fix te publiceren

## Scope

- Shell scripts
- Installatie scripts
- Configuratie bestanden
